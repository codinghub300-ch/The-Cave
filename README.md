# The Cave 

Live Demo:
https://the-cave-alpha.vercel.app/

An interactive cybersecurity puzzle game where players solve multiple security and forensic challenges to unlock hidden rooms inside a mysterious cave.

---

##  Game Concept

The Cave contains 4 secret rooms.  
Each room presents a unique cybersecurity challenge that must be solved before accessing the next room.

Players will use:
- Data Analysis
- Cryptography
- Network Forensics
- SQL Injection

to uncover secrets and complete the game.

---

##  Rooms Overview

###  Room 1 — The Ancient Data Scroll
Players analyze Excel datasets to detect outliers and identify hidden IDs and locations.

Concepts:
- Data Analysis
- Outlier Detection
- Excel Investigation

---

###  Room 2 — The Chamber of Runes
Players decrypt encoded messages and reveal the original hidden words.

Concepts:
- Cryptography
- Encoding & Decoding
- Cipher Analysis

---

###  Room 3 — Packet Hunter
Players navigate terminal commands, retrieve hidden files, analyze packet captures using Wireshark, and uncover encrypted secrets.

Concepts:
- Networking
- Packet Analysis
- Wireshark
- Linux Terminal Commands

---

###  Room 4 — Corrupted Database
Players exploit SQL Injection vulnerabilities to bypass restrictions and access hidden data.

Concepts:
- SQL Injection
- Database Exploitation
- Web Security
